# Менеджер Задач

Приложение для удобного управления задачами с поддержкой приоритетов, дедлайнов и локального хранения данных.

## Основные возможности

- **Добавление задач** — указывайте название, описание, дедлайн и приоритет
- **Приоритеты** — три уровня (MAX, MED, MIN) с цветовой индикацией
- **Дедлайны** — задачи с просроченными датами помечаются автоматически
- **Фильтрация** — просмотр всех, активных или завершённых задач
- **Сортировка** — умная сортировка: сначала высокий приоритет, затем ближайший дедлайн
- **Тёмная тема** — переключение между светлой и тёмной темой
- **Локальное хранение** — данные сохраняются на устройстве через SharedPreferences
- **Русификация** — полный интерфейс на русском языке
- **Обратная связь** — случайные поощряющие сообщения при завершении задач

## Технологии

- **Flutter** — кроссплатформенная разработка
- **Provider** — управление состоянием
- **SharedPreferences** — локальное хранение данных
- **flutter_localizations** — поддержка локализации

## Сборка и запуск

### Требования

- Flutter SDK >= 3.0.0
- Android SDK / iOS SDK
- Dart SDK

### Установка зависимостей

```bash
flutter pub get
```

### Запуск в режиме разработки

```bash
flutter run
```

### Сборка APK для Android

```bash
flutter build apk --release
```

### Сборка для iOS

```bash
flutter build ios --release
```

## Настройки приложения

### Переключение темы

Нажмите на иконку темы в правом верхнем углу экрана.

### Фильтрация задач

Нажмите на иконку фильтра в правом верхнем углу экрана и выберите:
- Все — показать все задачи
- Активные — только незавершённые
- Завершённые — только выполненные

### Добавление задачи

Нажмите кнопку `+` в правом нижнем углу:
- Укажите название (обязательно)
- Добавьте описание (по желанию)
- Установите дедлайн (по желанию)
- Выберите приоритет (MAX / MED / MIN)

### Редактирование и удаление

Нажмите на задачу для редактирования или удаления.
